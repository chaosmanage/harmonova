# HarmoNova branding

The app icon and README banner come from the supplied **Warm Monogram Wave App Icon** and **HarmoNova Cream Minimalist Banner** images. The original monogram artwork is the source for every Chrome extension icon and the popup/settings logos.

- `harmonova-icon.png`: raster monogram artwork used as the icon master
- `icon16.png`, `icon32.png`, `icon48.png`, `icon128.png`: image-derived Chrome extension icons
- `../docs/assets/harmonova-banner.png`: image-derived README wordmark banner
- `../docs/assets/harmonova-social-preview.png`: image-derived optional social preview

No hand-drawn logo SVG is used in the extension or README. UI action glyphs may still use inline SVGs for controls; they are not the app logo.

**Inspiration credit:** [Harmonic for Hacker News](https://github.com/SimonHalvdansson/Harmonic-HN) by Simon Halvdansson (Apache 2.0). This independently branded extension is not affiliated with or endorsed by the original developer.
